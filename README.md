# 工业过程数字孪生与异常根因推理服务

纯后端 Node.js + TypeScript + Fastify 项目，默认将状态持久化到本地 JSON 快照（`TWIN_STORE_PATH`，默认 `data/twin-store.json`），不依赖 Docker、数据库或消息队列。

## 运行

```bash
npm install
npm test
npm start
```

## 业务闭环

设备拓扑版本 → 遥测接入 → 时间序列重放 → 阈值异常检测 → 拓扑影响分析 → 根因候选 → 工单状态机 → 审计追踪。

关键不变量：拓扑版本连续且按生效时间选择；遥测事件按业务时间和系统序列重放（序列由事件身份确定性派生并随事件持久化，与写入顺序无关，重复 eventId 幂等去重，重启后顺序不变）；工单只能沿合法状态机迁移；所有重要操作产生审计记录。
